# Backend — Keleshek Site

Папка для серверной части. Здесь будет API, база данных и всё, что работает на сервере.

## Структура (заготовка)

```
backend/
├── README.md        ← вот этот файл
├── package.json     ← зависимости (когда добавишь сервер)
└── src/
    ├── index.ts     ← точка входа сервера
    └── routes/      ← API-маршруты
```

## Запуск (когда сервер будет готов)

```bash
cd backend
npm install
npm run dev
```
